# FYN Assurance und FYN Academy

FYN Assurance und FYN Academy sind öffentliche Angebotslinien für die Einführung und Qualifizierung rund um AAA Code. **FYN Assurance** ist ein Arbeitsname; vor einer Nutzung im Markt steht eine professionelle markenrechtliche Ähnlichkeitsrecherche aus. AAA Code bleibt der aktuelle Name des Open-Source-Pakets. Eine Umbenennung hat nicht stattgefunden.

## Portfolio

- **AAA Code:** Open-Source-Doctrine für den kleinsten vollständigen Weg am nativen Owner.
- **FYN Assurance:** begleitete Governance-, Kontroll- und Nachweisgestaltung für begrenzte Agenten-Rollouts.
- **FYN Academy:** praxisorientierte Qualifizierung für Führung, Engineering, Risiko und interne Prüffunktionen.

## Öffentliche Wahrheitsgrenze

Diese Unterlagen beschreiben ein Vorgehensmodell, Schulungsangebote und geplante Integrationsoptionen. Sie sind keine Zusage einer Produktfunktion, eines laufenden Dienstes, einer Rechtsberatung, einer Zertifizierung oder einer regulatorischen Eignung. Eine konkrete Einführung braucht einen schriftlich abgegrenzten Auftrag, eine technische und organisatorische Prüfung sowie die Entscheidungen der verantwortlichen Stellen.

AAA Code selbst bleibt bewusst ohne Runtime: keine Hooks, keine Daemons, keine Telemetrie, kein eigener MCP-Server, keine persistenten Modi und keine Approval Stores. Die maßgebliche Paket- und Evidenzgrenze steht im [Produktvertrag](../product-contract.md).
